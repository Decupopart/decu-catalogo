# Catálogo Decu

Catálogo web filtrable de Decu (cuadros en lienzo sobre bastidor).

## Cómo actualizar el catálogo
1. Reemplazar el array `PRODUCTOS` dentro de `index.html` (o cargar un `productos.json` aparte) con los datos generados desde `catalogo_procesado.csv`.
2. Subir los cambios a este repositorio.
3. GitHub Pages actualiza el sitio automáticamente en 1-2 minutos.
